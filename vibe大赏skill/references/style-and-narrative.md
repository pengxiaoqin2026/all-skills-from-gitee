# 风格与叙事

## 视觉风格

- 1920×1080 横屏，30fps；深蓝黑底 `#0A0A1E`，金色 `#E8C878`、暖白 `#F2EBD8`、青色 `#6FC3DF`。
- 无旁白，中英双语字幕；BGM 纯器乐（约 76–78 BPM 纪录片感，默认 We_Never.mp3）。
- 每个画面：常驻动态背景（径向渐变光 + 漂浮粒子 + 漂移柔光带）+ 一个专属图形 + 双语字幕。
- 图形是主题专属的：每做一个新主题，都要为该主题重新设计并生成图形，不复用上一主题或模板的图形。
- 图形与文字避让：图形默认落在右侧或下方空白带，不压在居中字幕上；实心大图形优先改描边 + 低透明度（约 7% 填充），且避免图形颜色与重叠文字同色（金标题不叠金色实心图形）。
- 元素错峰入场：一个接一个，从不同方向飞入（左滑/下升/缩放聚焦/右入），带旋转与模糊；就位后定格约 3 秒，期间保留轻微“呼吸/漂浮”。

## 叙事结构

最稳的两种：

1. 历史时间线（知识诅咒/运气的形状这类）：钩子（一个具体物件 + 反常识句）→ 标题卡 → 5 段“年份 + 地点 + 人物 + 一句贡献/反直觉点” → 现实落地 → 金句 + 引用。
2. 六段式：冷开场钩子 → 历史/文献锚点 → 机制动画 → 反直觉转折 → 现实落地 → 金句 + 引用。

每段时长按内容量分配：4 个元素 + 图形的段约 14 秒；两行字 + 图形的段约 10 秒；金句收尾约 12 秒。总长约 120–130 秒。

## 字幕与文案

- 每屏中文字数 ≤ 20；英文为辅助，不逐字直译。
- 数字必须能复算；出现“约/示意/一种解释”等限定词保留。
- 标题公式：生活场景 × 一个能叫出名字的理论；数字进标题。
