# 阶段二、三、四：配音文案、选图、字幕时间表

## 配音文案（文案.txt）

- 第一行是书名，只用于片头口播，不生成底部字幕。
- 第二行起是正文旁白。
- 正文最多 12 行、最多 140 个汉字，推荐总计 12 行。
- 每行不用标点符号，用空格断句；每行是一个完整朗读单元。
- 第一句直接制造共鸣；用短句和具体生活场景；结尾留余味。
- 不写书评、剧情梗概或 CTA；不用“你是不是”、反复“不是…而是…”或机械排比。

## 选图（正片 5 张，随机 + 双重去重）

- 从风格对应文件夹随机抽取：油画感=`E:\素材库\油墨画`，电影感=`E:\素材库\电影感`。
- 第 1 张作片头图，第 2–5 张对应正文 1–4 段氛围图；5 张必须互不相同（同一视频内不重复）。
- 最近 4 个视频里用过的图片不得再次使用（连续 4 个视频不重复）；使用记录保存在 `E:\codex_one\选图使用记录.txt`，每行一个视频、5 个图片标识用 `|` 分隔，只保留最近 4 行。
- 基本质量过滤仍要满足：3:4（或可居中裁切为 3:4）、顶部底部留白、无文字/书封/卡片/水印；随机抽完后在对话中目检，不合格再手动换一张。
- 优先用脚本随机选图（自动读记录 → 排除最近 4 个视频 → 随机抽样 → 写回记录 → 复制重命名）：

  ```bash
  python "C:\Users\Administrator\.codex\skills\read-book-video\scripts\select_images.py" "E:\素材库\电影感"
  ```

  换风格时替换最后一个目录参数（`E:\素材库\油墨画`）。加 `--dry-run` 只预览不落盘；加 `--seed 整数` 固定随机结果以便复现。
- 可用池不足 5 张时，脚本按“最久未使用优先”放宽复用更早的图片，并在输出中给出警告；整个目录不足 5 张则直接报错，此时向用户要素材。
- 选中后重命名为 `片头.png、正文1段.png、正文2段.png、正文3段.png、正文4段.png`，复制到 `E:\codex_one`，素材库原图不改动，并在对话中显示选中图片。

## 字幕时间表（字幕时间清单.txt）

- 输入：`文案.txt` 和 MiniMax TTS 生成的固定音色正片旁白 `正片.mp3`（音色 `Chinese (Mandarin)_Gentle_Youth`，语速约 0.9）。
- 第一行书名不做字幕；从第二行开始给正文字幕时间。
- 时间以正片 mp3 开头为 0 秒。
- 用 FFmpeg 检测真实停顿（主方法）：

```bash
ffmpeg -i 正片.mp3 -af "silencedetect=noise=-30dB:d=0.25" -f null - 2>&1
```

- Whisper 只用于辅助核对，不能把识别文字当作字幕；字幕文字必须来自 `文案.txt` 第二行之后。
- 若本机有 `whisper-cli.exe`，可用 `-l zh -ojf` 拿词级时间戳核对停顿边界。
- 为每一句列出开始时间和结束时间，格式：

```text
第1句|字幕内容|开始时间-结束时间
```

- 保存为 `E:\codex_one\字幕时间清单.txt`。

## 片头文案（片头文案.txt）

片头文案第一行是一句“钩子句”，第二行固定写“今日分享”。钩子句分三种语句模式，先依据阶段一的书籍信息清单和正文文案自动选定模式，再按模式生成句子。

### 三种语句模式

1. **陈述句**：直接给出判断或感受，语气笃定，适合情绪明确、可以下结论的观点。
   - 例：这是我听过最通透的一段话 / 这是我听过最伤感的一段话 / 一个人成熟的标志，是把日子过稳。
2. **反问句**：用反问强化认同，答案已含在问句里，适合有强共鸣、想让观众点头的处境。
   - 例：这世上最难的事，难道不是放过自己吗？ / 谁不是一边崩溃，一边硬扛呢？
3. **疑问句**：真正抛出问题引发好奇，适合观点开放、有悬念、想带观众往下听的选题。
   - 例：为什么越懂事的人，越容易委屈？ / 一个人是怎样慢慢把自己耗空的？

### 自动选模式（基于书籍信息清单 + 正文文案）

- 先读阶段一输出的书籍信息清单，抓取“最适合做成视频讲的一条观点”“观众最容易共鸣的处境”“这本书主要解决什么问题”，再结合正文文案的情绪基调判断。
- 观点是明确结论、情绪可断言（通透、伤感、治愈、残酷、清醒等）→ 用**陈述句**。
- 观点对应普遍困境、观众已有切肤之感、需要被戳中后点头 → 用**反问句**。
- 观点是开放问题、有悬念或需要引发好奇 → 用**疑问句**。
- 同一内容若多种模式都成立，选与书籍情绪基调更贴的一种；优先让钩子句“戳中处境”，不为了套模式牺牲准确性，并遵守阶段一“容易误解、不能夸大表述”的红线。
- 选定模式后生成钩子句：不超过 16 字，不要直接采用正文文案中的原句，重新生成一句正文文案里没有的内容；第二行固定写“今日分享”，整体不超过 20 字。

### 与前三次模式不同

- 模式使用记录保存在 `E:\codex_one\片头文案模式记录.txt`，每行一个模式（`陈述句` / `反问句` / `疑问句`），只保留最近 3 行。
- 生成前先读该文件取最近 3 行；本次选择的模式必须与最近 3 次生成时用过的模式不同。
- 若最近 3 行已覆盖全部 3 种模式、无法再做到三者都不重复，则选最久未使用的那一种（即最早出现的那一行对应的模式），按最久未使用轮换，避免连续重复。
- 生成后把本次使用的模式追加到记录文件末尾，再裁剪为最近 3 行。
- 保存 `E:\codex_one\片头文案.txt`。
